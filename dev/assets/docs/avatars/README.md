# Futurama character portraits

These unmodified WebP images were downloaded from [FuturamaAPI](https://futuramaapi.com/) on 2026-10-29 for the Cinder UI documentation and demo. No runtime API calls are made.

The portraits depict copyrighted Futurama artwork. The API’s code license does not grant a license to the artwork, and these images are not covered by Cinder UI’s MIT license. Source links are retained below; applications copying the component examples should provide their own images.
